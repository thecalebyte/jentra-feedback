# Jentra feedback

This public repository is the issue tracker for the proprietary Jentra experimental prototype. It
does not contain Jentra's source code and does not grant an open-source licence.

- Use the issue chooser to report a reproducible bug or request an improvement.
- Read the installation guide supplied with your Jentra distribution before reporting setup issues.
- Public issues are visible to everyone. Remove credentials, tokens, private repository content,
  Journey data, customer information and unsanitised logs or screenshots.
- Do not file security vulnerabilities as public issues. Use this repository's private vulnerability
  reporting form when it is available.

Jentra does not automatically upload logs or Journey content. Everything attached to an issue is
submitted deliberately by the reporter.
