# Security reports

Do not disclose a suspected vulnerability, credential, private repository content or sensitive
Journey data in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/thecalebyte/jentra-feedback/security/advisories/new) for sensitive security
reports. If that form is unavailable, do not publish the details; retain them until a private route
is available. No support email address is implied by this repository.
